# 분할점수(추정분할점수) 산출 절차

2025~2026학년도 학교 안내문(산출 안내, 가정통신문, 회의록)과 교육부·경기도교육청 자료를 정리한 문서다.
검증은 `/cutoff` 페이지와 `lib/cutoff.ts`에서 할 수 있다. NEIS 내부 산출식은 공개되어 있지 않아, 이 문서와 도구는 "입력 규칙"과 "절차"만 다룬다.

## 배경

- 2025학년도부터 모든 고등학교는 NEIS의 추정분할점수 산출 기능을 필수로 사용한다
  (학교생활기록 작성 및 관리지침, 교육부훈령 제504호 부칙).
- 고정분할점수: 기준 성취율과 원점수를 1:1로 대응(90, 80, 70, 60, 40점).
  추정분할점수: 교과 특성과 문항 난이도를 고려해 교사 협의로 기준 성취율에 해당하는 점수를 추정.
- 과목별로 어느 방식을 쓸지는 교과 회의록에 정한다(예: 통합과학2는 추정, 물리학Ⅰ은 고정).

## 절차

NEIS 경로는 모두 `교과담임 > 성적` 아래다.

1. **성취기준관리 입력**: `지필/수행선행작업 > 성취기준관리`에서 국가교육과정 성취기준을 가져와 저장.
2. **문항정보표관리**: 내용영역, 성취기준, 난이도, 배점, 정답을 입력하고 마감.
   마감하지 않으면 분할점수를 산출할 수 없다. 마감 후에는 성취기준, 난이도, 배점을 바꿀 수 없다.
   같은 배점은 반드시 같은 난이도로 쓴다(예: 배점 3.1에 중과 하를 섞지 않는다).
3. **정기시험 추정분할점수**: `분할점수 > 분할점수관리 > 지필평가추정분할점수산출관리`
   (공동 담임이면 모든 교사가 입력).
   라운드 등록, 평가단계 선택, 최소능력자 예상정답률 입력, 저장, 입력마감, 교사별입력정보조회에서 마감 확인.
   2라운드 이상 실시하는 것이 원칙이다. 2라운드는 복사대상라운드 "1"로 등록하면 1라운드 값이 복사된다.
   `추정분할점수산출결과관리`에서 1라운드와 2라운드 중 하나를 선택해 확정한다(평균이 아니다).
   승인요청, 결재자 지정(연구부장, 교감), 상신 후 결재 완료를 기다린다.
4. **수행평가 추정분할점수**: `분할점수관리 > 수행평가추정분할점수산출관리`.
   공동 담임이어도 한 명만 입력한다. `전체영역`을 선택하고 성취수준별 분할점수를 입력한다(성취율은 교과담임이 정한다).
   학기에 따라 입력 후 마감, 승인요청, 결재를 거친다.
5. **학기말 추정분할점수산출**: `분할점수관리 > 학기말 추정분할점수산출`에서 산출한다.
   2025학년도 2학기 이후 안내문은 승인요청, 결재, 마감 순서가 있다.
   `전체과목출력` 결과를 PDF로 저장해 교과부장에게 보낸다.
   파일명 예: `2026학년도 1학기 O학년 OO과 분할점수(2차 정기시험, 학기말)`.

## 정기시험 예상정답률 입력 규칙

| 규칙 | 내용 |
| --- | --- |
| 입력 단위 | 5% 단위. E는 정수 입력 가능 |
| 최솟값 | 5% 이상(E에 0 입력 불가) |
| 인접 수준 차이 | A-B, B-C, C-D는 15% 이하. D-E는 19%까지 |
| 위반 시 | 20% 이상이면 입력마감 후 해당 칸 테두리가 적색이 되고 분할점수 산출 불가 |
| 공동출제 | 같은 수준의 예상정답률이 교사 사이에 15% 이하 차이 |
| 평가단계 | 5수준(A-E). E/I(미도달) 단계 교과는 I까지 선택 |
| 마감 | 입력마감취소 불가. 문항 오류로 인한 만점 변동이나 전면 재시험일 때만 재산출 허용. 잘못 입력했으면 라운드 삭제 후 재입력 |

## 수행평가 입력 규칙

- E/I(미도달) 단계 교과: E는 0 불가. E와 I를 나누는 성취율 40%를 곱해 입력하고, E 점수는 수행평가 기본점수를 초과해야 한다.
  예) 52점 만점, 성취율 A90 B70 C60 D50 E40 이면 46.8, 36.4, 31.2, 26, 20.8 (정수는 47, 36, 31, 26, 21).
- 나머지 교과: E는 0을 입력하고, D 점수가 수행평가 기본점수를 초과해야 한다.
  예) 52점 만점, 성취율 A90 B70 C50 D40 이면 46.8, 36.4, 26, 20.8 (정수는 47, 36, 26, 21).
- 분할점수는 소수도 입력할 수 있다(2025학년도 1학기 공지에 42.6, 35.1 같은 값이 있다).
- **안내문마다 E/I 단계 대상이 다르다**: 2025학년도 안내는 "1학년", 2026학년도 1학기 PDF 안내는 "1, 2학년",
  같은 학기 hwpx 안내는 "1학년"으로 적혀 있다. 해당 학기 안내문을 확인한다. 도구에서는 체크박스로 받는다.

## 학기말 점검

- 성취수준 A의 분할점수가 과목 평균보다 낮으면 안 된다.
- 성취수준 A의 비율이 상한보다 높으면 안 된다.
  상한은 안내문마다 다르다: 2025학년도 2학기 1차 32.8%, 2026학년도 1학기와 2학기 안내 23.9%. 도구에서는 값을 입력으로 받는다.

### 학기말 분할점수 근사값

2025학년도 2학기 통합과학2(1학년) 출력본으로 다음 식을 확인했다.

```
학기말 분할점수 ≈ Σ (평가별 분할점수 ÷ 만점 × 반영비율)
```

정기시험은 100점 기준이고 수행평가는 수행 만점 기준이다.
1차 정기시험 반영 24%, 2차 정기시험 24%, 수행 52%(만점 52)에서 계산값이 92.6, 81.4, 68.2, 55.0, 31.1이고
출력본은 92, 81, 68, 55, 31이다. 반올림 규칙(A/B는 92.6이 92, D/E는 54.99가 55)은 확정하지 못했다.
다른 과목과 학년으로 더 확인하기 전까지는 근사값으로만 쓴다.

## 출처 목록

- NEIS 분할점수 기능 개선 및 사용 안내(교실혁신지원과, 2025.3.12)
- 경기도교육청 고등학교 성취평가 추정분할점수 이렇게 산출해요 [실전편]
- 학교 분할점수 산출 안내(2025학년도 1학기~2026학년도 2학기), 지필·수행평가 분할점수 공지, 교과 회의록
