# 자리 배치표

짝꿍(2인) 분단형 교실의 자리 배치표를 만드는 웹앱입니다.

- 선생님 이메일+비밀번호 로그인, 선생님마다 배치표 1개 저장 (Supabase, RLS로 본인 것만 접근)
- 학생 명단 붙여넣기, 무작위 섞기, 끌어서 자리 바꾸기
- 앞줄 우선 학생, 떨어져 앉을 학생 묶음 (짝·앞뒤·옆·대각선 금지)
- 인쇄: 1쪽 전자칠판이 위, 2쪽 180° 돌린 모습
- 분할점수 점검(`/cutoff`): NEIS 입력 전에 예상정답률·수행평가 분할점수 규칙을 검사. 절차는 `docs/cutoff-scores.md`

## 개발

```bash
npm install
npm run dev     # .env.local 에 NEXT_PUBLIC_SUPABASE_URL, NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY 필요
npm test        # 자리 배치 로직 테스트
```

DB 변경은 `supabase/migrations/`, 되돌리기는 `supabase/rollback.sql` 에 있습니다.

## Supabase 무료 플랜이 일시 중지될 때

무료 플랜은 약 1주일 접속이 없으면 프로젝트가 일시 중지되어 로그인과 가입이 `Failed to fetch`로 실패합니다.

- 예방: `vercel.json`의 Cron이 하루 한 번 `/api/keepalive`를 호출해 데이터베이스에 가벼운 요청(`ping()` 함수)을 보냅니다. `supabase/migrations/20261105000000_add_ping.sql`을 한 번 실행해 두어야 합니다.
- 이미 중지되었다면: Supabase 대시보드에서 프로젝트의 "Resume project"(한국어 번역으로는 "이력서 프로젝트")를 눌러 다시 시작합니다. 중지 후 일정 기간 안에만 가능합니다.

## 누가 무엇을 보나
- 링크만 있는 방문자(로그인 없음): 분할점수 안내, 분할점수 공지(가정통신문만). 올린 자료의 값(협의록 장소·참석자·기록자, 추정분할점수, 편제표 과목)으로 자동 채우기를 쓴다.
- 관리자(`public.admins`에 등록된 계정): 위에 더해 자리 배치표, 학업성적관리회의 자료, 점검 도구, 편제표, 자료 첨부. 관리자 로그인은 `/login`(분할점수 페이지 위쪽 "관리자 로그인").
- 화면에서 숨기는 것은 편의이고, 실제 보호는 DB 규칙이 한다: 올리기는 관리자만, 자리 배치표 데이터는 본인만(`owner_id`), 파일 원본은 로그인한 사용자만. 방문자용 읽기는 `supabase/migrations/20261105030000_public_plan_read.sql`로 연다.

## 올린 자료 보관(자료 첨부 탭)

관리자가 평가계획서 교과별 협의록과 학년별 추정분할점수 파일(hwpx, xlsx, pdf)을 올려 두면, 안내·공지 탭에서 불러와 칸을 채웁니다.

- 열람은 로그인한 사용자 모두, 올리기는 관리자만 할 수 있습니다. 올린 자료는 지우거나 고칠 수 없고, 정정은 새 판으로 추가됩니다.
- 처음 설정(Supabase SQL Editor에서 한 번):
  1. `supabase/migrations/20261105010000_plan_uploads.sql`의 내용을 실행합니다.
  2. (편제표를 올리려면) `supabase/migrations/20261105020000_curriculum_uploads.sql`의 내용도 이어서 실행합니다.
  3. (방문자 자동 채우기를 쓰려면) `supabase/migrations/20261105030000_public_plan_read.sql`의 내용도 이어서 실행합니다.
  2. 관리자를 등록합니다. 아래 `관리자 이메일`을 본인 이메일로 바꿔 실행합니다.

     ```sql
     insert into public.admins (user_id)
     select id from auth.users where email = '관리자 이메일';
     ```
- 회원가입이 열려 있으면 가입한 누구나 올라온 자료를 볼 수 있습니다. 협의록에는 선생님 이름이 들어 있으니, 선생님 계정을 만든 뒤 Supabase 대시보드의 Authentication, Sign In / Providers에서 새 사용자 가입을 끄는 것을 권합니다.
- 협의록 PDF(글자가 들어 있는 PDF)는 교과, 장소, 참석자, 기록자와 "과목별 정기시험 및 수행평가 반영 비율" 표를 읽어 옵니다. 읽은 값은 화면에서 확인하고 고친 뒤 저장하며, 교과협의록 탭에서 교과를 고르면 과목 줄까지 채워집니다. 스캔한 그림 PDF는 읽지 못합니다. 추정분할점수는 NEIS의 "학기말 추정분할점수" 엑셀(xlsx)과 PDF(글자가 들어 있는 PDF)를 읽습니다. 구분 표기가 해마다 달라서 "지필/수행"(~2026년 1학기)과 "정기시험/수행평가"(2026년 2학기) 두 가지를 모두 읽습니다. 학년마다 파일 하나를 올리면 1차 정기시험, 수행평가, 2차·학기말 표가 한꺼번에 채워지고(해당 자료가 있는 시험만), 공지 탭에서 불러옵니다. 이 엑셀에는 추정분할 과목만 있어서, 공지 탭 '불러오기'가 편제표의 나머지 과목(성취도 5단계·3단계)을 고정분할 묶음으로 채웁니다(5단계 90/80/70/60[/40], 3단계 80/60/0/·[/·]; 협의록에서 정기시험을 보지 않는다고 확인되면 정기시험 칸은 -). 3학년처럼 추정분할 자료가 없는 학년은 편제표의 모든 과목이 고정분할로 채워집니다. 표를 읽지 못한 파일(스캔 PDF, 다른 서식)은 파일만 보관하고 값은 직접 붙여넣습니다.

## 여러 파일 한꺼번에 올리기(자료 첨부 탭)
자료 첨부 맨 위의 '여러 파일 한꺼번에 올리기' 칸에 파일을 여러 개 끌어다 놓으면 파일마다 종류(교과협의록 hwp·pdf, NEIS 추정분할점수 엑셀·pdf, 편제표 hwp)와 교과·학년을 알아내 위에서 고른 학년도·학기로 바로 저장합니다(`lib/plans/analyze.ts`). 교과·학년을 알아낼 수 없는 파일, 학기가 다른 파일, 이미 올린 자료가 있는 파일은 저장하지 않고 이유를 보여 줍니다. 정정은 각 구역의 '이 판으로 정정'으로 합니다.

## 편제표(자료 첨부 탭)
NEIS의 "학교교육과정 편제 및 시간배당 관리 보고서"(hwp)를 학년마다 올립니다(관리자만, 정정은 새 판). 파일에서 교과별 과목과 성취도 단계(성적처리유형의 5단계·3단계)를 읽어 화면에서 고칠 수 있게 보여 주고, 저장하면 교과협의록의 과목 줄이 편제표대로 채워집니다: 과목명 선택지, 성취도 단계(5/3), 과목 줄이 비어 있으면 그 교과의 과목 전체. 이진 hwp는 `lib/plans/hwp.ts`가 읽고(CFB + 압축 해제), 표 모양은 `lib/plans/curriculum.ts`가 되살립니다. hwpx·pdf·xlsx 편제표는 아직 읽지 못합니다. 학기마다 개설 과목이 달라 편제표는 학년도·학기별로 올립니다.
